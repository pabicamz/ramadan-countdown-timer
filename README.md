# Ramadan Countdown Timer

A simple, countdown timer for the start of Ramadan - built with vanilla HTML, CSS, and JavaScript.

## Features

- Live countdown to Ramadan 2027 (days, hours, minutes, seconds)
- Real-time clock and date display
- Fetches the target date dynamically from the [zakiego Ramadan API](https://ramadan.zakiego.com/api/countdown) instead of a hardcoded date
- Falls back gracefully to a local date if the API is unreachable
- Fully responsive layout

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

## API

This project uses the open-source [Ramadan Countdown API](https://github.com/zakiego/ramadan-countdown) by [zakiego](https://github.com/zakiego) to fetch the current countdown target date.

## Running Locally

1. Clone the repo

   git clone https://github.com/pabicamz/<repo-name>.git
